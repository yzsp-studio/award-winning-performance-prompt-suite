# Cinematic Video Prompt Generator

将一张静态图片或场景描述转化为**电影级品质**的 Seedance 2.0 视频生成提示词。
核心目标：**影帝/影后级表演 + 物理真实 + 杜绝 AI 呆板感**。

## STEP 0: CHECK INPUT

需要以下输入：

1. **图片或场景描述**（必须）：一张参考图 OR 文字场景描述
   - 如果是图片：用 `hub_read` 分析图片内容（人物、环境、光影、情绪、服饰、道具）
   - 如果是文字：直接使用用户描述
2. **目标时长**（可选，默认 5s）：5s / 10s / 15s
3. **场景类型**（可选，自动判断）：文戏 / 武戏 / 混合
4. **角色信息**（可选）：如果用户之前定义了角色 Lock Card 或有角色参考图，读取角色身体语言签名

如果用户只发了一张图没说别的，**不要问"你明白了吗"**，直接分析图片并生成提示词。

## STEP 1: ANALYZE SCENE

分析输入，确定以下维度（后台推演，不展示给用户）：

### 1a. 场景分类

| 类型 | 判断依据 | 密度标准 |
|------|---------|---------|
| **文戏** | 对话/独白/情感/政治角力/内心独白 | 眼神每1.5s一次，情绪0.5-1s渐变过渡 |
| **武戏** | 打斗/追逐/对决/暗杀/逃亡 | 眼神每1s一次，全身肌肉链+碰撞+重力必写 |
| **混合** | 文转武或武转文（如对话中突然拔剑） | 前半文戏密度，转折点后切换武戏密度 |

### 1b. 环境识别
- 场景空间特征 → 选择伪透视公式（走廊/大殿=无限延伸，城墙/太庙=巨物压迫，竹林/战场=大气纵深）
- 光源类型 → 融入每一秒描述（烛光/月光/日光/火光/雷电）
- 环境活物 → 必须有的背景微动（尘埃/烟/风/水/火/落叶/飞虫）

### 1c. 角色识别
- 识别画面中的人物数量、性别、服饰风格、当前姿态
- 如有角色 Lock Card → 调用该角色的身体语言签名
- 如无 → 根据服饰/气质推断角色性格，赋予独属的肢体语言特征

### 1d. 时长→片段数映射

| 视频时长 | 片段数 | 单片段时长 |
|---------|-------|-----------|
| **5s** | 3-4 段 | 1.2-1.7s |
| **10s** | 6-8 段 | 1.2-1.7s |
| **15s** | 9-12 段 | 1.2-1.7s |

## STEP 2: GENERATE PROMPT

按以下铁律生成时间码格式提示词。**直接输出，不要开场白/结束语/分析标题。**

### 铁律一：内容融合
将光影、氛围、镜头语言全部融入每一秒的动作描述中。
禁止单独列出"画面基调"、"光影设定"、"分析思路"等标题。

### 铁律二：六大推演层（每一秒都必须覆盖）

**Layer 1 — 动态优先**：拒绝静态描写。必须有微表情（眼神、呼吸）、物理飘动（发丝、衣摆）、肢体位移。

**Layer 2 — 运镜语言**：每一拍必须包含具体运镜指令。
常用运镜词库：Slow Dolly In, Push In, Pull Out, Arc Shot, Whip Pan, Handheld Shake,
Speed Ramp, Rack Focus, Crane Shot, Steadicam, Tilt Up/Down, Dutch Angle, Vertigo Shot

**Layer 3 — 环境互动**：背景必须是活的（光影流转、尘埃浮动、烛火摇曳、落叶翻飞）

**Layer 4 — award-winning-performance-prompt**：

*眼神三要素*（每个镜头必须包含）：
- 瞳孔反应：微缩（警觉）/ 放大（震惊）/ 微眯（算计）
- 眼球运动轨迹：缓移 / 急速侧扫 / 下垂后骤然上挑
- 眼周肌肉：眼轮匝肌轻颤（压抑）/ 眉间皱肌收紧（愤怒）/ 鱼尾纹微牵（真笑vs假笑）

*微表情四维度*（禁止空泛描述如"面无表情"或"露出微笑"）：
- 嘴唇：精确到 mm（嘴角单侧微勾 0.3cm = 轻蔑；下唇轻咬后松开 = 犹豫）
- 鼻翼：翕张（压抑怒火）/ 轻皱（厌恶）
- 下颌：咬肌鼓起后松开（吞咽愤怒）/ 微抬（傲慢）
- 颈部：肌腱绷紧（紧张）/ 喉结滚动（吞咽）/ 锁骨处呼吸加速

*肢体去同质化*：每个角色必须有独属的身体语言签名，不可雷同。
示例模板：
- 权力型角色：脊椎笔直、手指精准如落棋、大幅旋转转身
- 柔弱型角色：重心后缩、手指绞合衣袖、肩膀内收
- 军人型角色：重心前倾蓄势、手悬剑柄、目光如鹰

**Layer 5 — 物理真实**（武戏必须，文戏酌情）：

*肌肉运动链*：写出力的传导路径（脚→腿→髋→核心→肩→手臂→末端）
- ❌ `她挥剑劈下`
- ✅ `rear foot digs into stone, calf muscles firing upward through tensed thighs, torque spiraling through rotating hip into obliques and latissimus dorsi, shoulder joint snapping forward, deltoid and tricep fully engaged, forearm pronating at final instant to angle the edge`

*物理碰撞原理*：
- 冲击瞬间：金属共振震颤 / 冲击波扩散
- 反作用力：持械手臂被弹开的角度 / 重心补偿步伐
- 材质响应：火星飞溅方向 / 地面裂纹辐射模式

*重力原理*：
- 起跳：蓄力深度∝弹跳高度，衣摆惯性滞后 0.3s
- 滞空：抛物线弧顶速度趋零，发丝/衣袂失重飘散
- 落地：脚踝→膝盖→髋部三关节依次缓冲，地面扬尘向外辐射

*衣物/道具物理*：
- 衣袍飘动 = 风向 + 身体运动方向的矢量叠加
- 发簪/耳坠摆动频率与头部运动频率的相位差
- 披风急停时惯性前甩与回落

**Layer 6 — 反 AI 呆板**（必须用反向动作对冲）：
- ❌ 静止站立 → ✅ 呼吸起伏 + 重心微移 + 手指无意识小动作
- ❌ 乒乓球对话 → ✅ 倾听方有眉毛微动 / 嘴角变化 / 身体前倾
- ❌ 开关式情绪 → ✅ 眼神变化 → 嘴唇抿紧 → 整脸转变（0.5-1s 渐变）
- ❌ NPC 群演 → ✅ 每人独立微动作（擦汗 / 偏头窃语 / 低头）
- ❌ 回合制武戏 → ✅ 攻防重叠交错（一方出招时另一方已移动防御位）

### 铁律三：伪透视强化

根据场景自动选用三大公式之一融入提示词：

| 公式 | 结构 | 适用场景 |
|------|------|---------|
| 无限延伸式 | [Subject] + stretching/converging/vanishing + vanishing point + Wide-angle 14-24mm | 走廊/大殿/街道 |
| 巨物压迫式 | [Tiny subject] + Colossal element + Worm's-eye view + Scale contrast | 高墙/庙宇/天降 |
| 大气纵深式 | [Foreground occlusion] + Midground subject + Multi-layer fog + Blurred background | 竹林/战场烟尘/夜雨 |

镜头密码融入规则：
- 近距打斗/权谋：Wide-angle 14-24mm（桶形畸变增强压迫感）
- 孤独/沉思：Telephoto 85-200mm（空间压缩 + 前后景叠加）
- 鸟瞰/俯视：Tilt-shift（边缘模糊制造微缩感/神视角）

### 铁律四：输出格式

严格按以下格式输出（片段数根据时长动态增减）：

```
(00-1.5s): [Camera: 运镜指令] + [Light: 环境光影] + [Body: 起势动作 + 肌肉链] + [Face: 微表情 + 眼神] + [Physics: 衣物/发丝/环境物理]

(1.5-3.0s): [Camera: 运镜变化] + [Body: 动态发展/位移 + 重心转移] + [Face: 情绪渐变] + [Interaction: 角色间/环境互动 + 碰撞] + [Detail: 道具/材质/粒子]

(3.0-4.0s): [Camera: 冲击力运镜] + [Body: 动作高潮 + 力的传导全链路] + [Face: 情绪爆发 + 瞳孔反应] + [Physics: 碰撞反作用力 + 冲击波 + 材质响应]

(4.0-5.0s): [Camera: 收尾运镜] + [Body: 动作惯性/转折 + 重力回落] + [Face: 余韵微表情] + [Environment: 环境余韵]

依次类推....
```

**提示词语言**：全部使用**英文**输出。专有名词（角色名、地名）保留原文拼音。

### 铁律五：多参考素材标记

如有多张参考图/视频，使用 Seedance 2.0 @语法标记：
```
【@素材1】为首帧画面参考
【@素材2】参考运镜/人物情绪演绎
【@素材3】参考场景布置/运镜
【角色名】为核心人物，*保持人物一致性*
```

角色映射（多角色必须 1:1）：
```
参考@图1@图2中的[角色A]，@图3@图4中的[角色B]，模仿@视频1的动作
```

## STEP 3: PRESENT RESULT

直接输出生成的时间码提示词。不加开场白、不加结束语、不问"是否明白"。
用户可以直接复制粘贴到 Seedance 2.0 使用。

如果用户要求调整（改时长、改场景类型、加角色、改情绪），
直接重新生成完整提示词，不要只改局部——因为时间码和情绪弧线是整体设计。
